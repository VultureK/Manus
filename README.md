# Welcome to Manus
Manus was made for simple writing. Whether you just want a basic text editor, you're writing a manuscript, or you're like me and you like extremely simple things, Manus has only what you need.

Manus comes completely free. There are no subscriptions or payments (there **NEVER** will be). I've gotten pretty sick of having to pay or log-in in order to use something like this.

## List of features
1. Text editing and writing
2. Basic formatting (text color, font, font size, Headings, etc.)
3. Create as many notes as you want (they are saved in your browser or you can download them as Markdown, .txt, or PDF files)
4. Different themes (Light, Dark, Retro)
5. View Markdown and .txt files easily + edit them

More features will be added in the future! For now, happy writing :)

## Tips
- Choose a theme of your own!
- If you don't want text indenting, go into Options and click "Turn Off Indenting"
- If you want to add a list of any kind, also go into Options.
